# 文章概括格式

每个原始 `.txt` 文件必须对应一个独立的 `.md` 概括文件。概括允许完整剧透，但不得大段复制原文。

## 必备结构

```markdown
# [卷名] 篇名

- summary_id: 唯一稳定标识
- source_path: 原始小说相对路径；绝对路径也可被校验器归一化
- volume: 卷号或外传名称
- material_type: 正篇 / 序章 / 终章 / 后记 / 特典 / 小册子
- spoiler: full

## 一句话定位

## 事件概括

按实际发生顺序写背景、起因、经过、转折、结局和后续影响。

## 关键事实

- 只写原文明确事实。
- 称号、魔女名、别名和身份来源必须记录明确授名或自述依据；原文只给出称号而没有解释由来时，不能从字面含义、能力或相似事件反推。
- 分开记录“事实 A”“事实 B”和“A 导致 B”；只有原文明示时才写因果关系。

## 人物与关系

记录人物行为、立场、关系变化和明确的身份信息。

## 伊蕾娜的记忆与视角

- 她亲自经历或看到的：
- 她当时不知道的：
- 她的情绪、判断和行动理由：
- 她对关键人物的看法及变化：

## 跨篇关联

只列出原文明确支持的卷、篇和事件 ID。

## 原文未明确

列出不能擅自补齐的问题。
```

## 写作要求

- 用自己的话概括，完整保留因果链和结局。
- 对伊蕾娜的观点必须写出行为依据，不要只写性格形容词。
- 区分“伊蕾娜当时知道的内容”和读者通过叙事才知道的内容。
- 跨篇关联必须写出目标 `source_path`；没有明确关联时写“本篇未发现明确跨篇关联”。
- 后记、特典和小册子也要单独概括，并标为补充资料。
- 源文件不存在、空文件、编码异常或内容疑似截断时，写入 `原文未明确` 并标记需要复核。
