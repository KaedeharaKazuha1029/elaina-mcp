## 一句话定位

伊蕾娜把扫帚变成人形去买饭，扫帚因同情滞销的小妖精化妆品而买下它，伊蕾娜则说价值取决于自己的标准而非价格。

## 事件概括

伊蕾娜在 C 国接受麻烦委托，预定在旅馆闭关一阵子，便把扫帚变成人形，给她三枚金币买午餐和晚餐。扫帚抱怨难得变成人却只被当成跑腿工具，伊蕾娜说明钱也可用来买她喜欢的东西。扫帚先到面包摊，因外貌与一名灰发魔女相同被老板娘认错；她买了伊蕾娜喜欢的畅销、便宜面包。

扫帚看到化妆品店门口大量滞销的小妖精化妆品。这种商品从邻国 A 国进口，在富裕国家流行，能让魔法形成的小妖精亲吻客人并改善皮肤；但在 C 国，小妖精外形被多数人嫌恶，价格又高，商品只好放在半价花车上。扫帚因不忍看见“同胞”无法发挥作用，买下其中一个，花光剩余的钱。

回到旅馆，伊蕾娜说明自己正受 C 国化妆品店委托，分析小妖精化妆品的成分。C 国店家承认正牌化妆品确实有效，但想去除昂贵且不受欢迎的小妖精效果，制造便宜仿制品。伊蕾娜总结：昂贵商品包含创新和制造特别性的努力，便宜商品包含让更多人买得起、流通的努力；价值取决于购买者自己的标准，价格不能单独衡量好坏。

扫帚问自己属于高价值还是低价值物品，伊蕾娜回答“你是我的东西”。一个月后，伊蕾娜在另一国遇到便宜版小妖精化妆品的推销，拿出随身携带的同款商品，说明自己携带它正因为它是自己的、无价的好东西。

## 关键事实

- 伊蕾娜能用魔法把自己的扫帚变成人形；扫帚没有对外公开的名字，明确身份是伊蕾娜的持有物。
- 伊蕾娜给扫帚三枚金币，要求买两餐，且允许她购买喜欢的东西。
- 小妖精化妆品来自邻近 A 国，正牌有小妖精效果；C 国消费者普遍不喜欢其外形，因此滞销。
- 伊蕾娜受 C 国化妆品店委托分析成分，店家希望制造去除小妖精效果的便宜类似品。
- 伊蕾娜把扫帚视为属于自己的无价物；她没有给出可换算的金钱价格。

## 人物与关系

- 伊蕾娜：表面把扫帚当工具，实际允许她花钱买喜欢的物品，并明确肯定她属于自己的重要物件。
- 扫帚：有独立意识、会抱怨和判断价值；她买面包和化妆品时以伊蕾娜的喜好及自身同情心行动。
- C 国化妆品店：关注价格与市场适配，希望用正牌成分做便宜商品。

## 伊蕾娜的记忆与视角

- 她亲自经历/看到的：本篇由扫帚第一人称讲述，伊蕾娜在旅馆收货、分析化妆品并与扫帚对话；后段她拒绝别国推销。
- 她当时不知道的：委托分析最终会制造出怎样的产品、小妖精化妆品在各国后续销量未明确。
- 她的情绪、判断和行动理由：她认为自己只是按价值观挑选物品，允许扫帚自由花钱；对扫帚的问题给出简短但明确的归属式回答。
- 她对关键人物的看法及变化：她没有把扫帚当作普通低价工具，而是把其价值定义为“我的东西”；对价格与质量没有绝对判断。
